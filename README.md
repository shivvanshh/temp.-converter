# Temperature Converter

A high-contrast, holographic chemistry temperature converter that seamlessly transforms between Celsius, Fahrenheit, and Kelvin.

## Features
- **Holographic Data Display**: Sci-fi frame and internal grids emitting a solid C3FF00 neon glow.
- **Deep Black Hull**: True-black transparent surfaces create higher contrast behind data.
- **Micro-Animations**: Hover-state interactions on reference points like Boiling, Freezing, and Body Temp.
- **Interactive Scrubber**: Synchronized horizontal scrubber with accurate alignments across all temperature scales.

## Walkthrough

The interface upgrades the original components into a pure C3FF00 dark-mode experience. Performance optimizations include isolating the Spline 3D scene, offloading blur rendering via hardware acceleration, and implementing an idling canvas loop to dramatically improve frame rates.
